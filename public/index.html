색상 팔레트

장바구니와 할일을 서로 다른 색으로 꾸며 한눈에 구분해요. 고르는 즉시 바뀌어요.

사용법

기본

  • 위 칸에 적고 Enter(또는 추가). 왼쪽 동그라미를 누르면 체크, 글자를 누르면 고치기, 오른쪽 X는 지우기예요.
  • 잘못 지우거나 체크했으면 아래에 뜨는 되돌리기를 누르세요.
  • 탭: 전체는 둘 다 한눈에, 장바구니·할일은 하나씩. 전체 탭에서는 입력칸 왼쪽에서 어느 목록에 넣을지 골라요.

장바구니 적는 법

  • 다이소 우유 2개 → 구입처 다이소, 우유, 수량 2개로 나눠져요.
  • 앞 단어가 아는 가게(다이소, 이마트, 쿠팡, 편의점, 약국, 주유소, 철물점 등이나 한 번 쓴 가게)이거나 동네마트, 행복약국, SK주유소처럼 가게 이름으로 끝나면 구입처로 읽어요.
  • 처음 쓰는 가게는 @동네마트 두부 또는 동네마트: 두부. 다음부터는 @ 없이 "동네마트 두부"만 써도 돼요.
  • 구입처 버튼을 누르면 그 가게에서 살 것만 보여요. 그 상태로 적으면 자동으로 그 가게 항목이 돼요.

할일 적는 법

  • 앞에 날짜를 쓰면 마감일: 오늘 세차, 내일 병원, 11/17 관리비, 11월 17일 회의. 날짜가 없으면 마감없음.
  • 반복: 매일 약 먹기, 매주 월 분리수거, 매월 15일 관리비. 완료하면 다음 날짜로 새로 생겨요.
  • 마감이 가까운 순서로 정렬되고, 지난 할일은 빨갛게 보여요.

끝낸 것과 완료 기록

  • 체크한 항목은 아래 접힌 칸(담은 것·완료)으로 내려가요. 다시 누르면 되돌아와요.
  • 7일이 지나거나 기록으로 보내기를 누르면 목록에서 빠지고, 오른쪽 위 완료 기록에 카드로 남아요. 지워지지 않아요.
  • 완료 기록의 자주 한 것에서 몇 번 했는지 보고, 카드의 다시 추가로 바로 목록에 넣을 수 있어요.

나만의 색상

  • 오른쪽 위 색상(팔레트 모양, 휴대폰은 그림만) 버튼에서 장바구니와 할일의 색(10가지)을 따로 골라요. 고르는 즉시 바뀌어요.
  • 로그인 중이면 내 계정에 저장돼 다른 기기에서도 같은 색이고, 아니면 이 기기에 저장돼요. 기본 색으로를 누르면 처음 색으로 돌아가요.

PC·태블릿 큰 화면

  • 화면이 넓으면 오른쪽 위에서 좁게 / 나란히 / 보드를 고를 수 있어요.
  • 보드는 가게별·마감별 칸으로 펼쳐져요. 항목을 마우스로 끌어 다른 칸에 놓으면 구입처나 마감일이 바뀌고, 완료 칸에 놓으면 체크돼요.
  • 전체 탭(보드·나란히)에서는 장바구니 ↔ 할일 사이로도 끌어 옮길 수 있어요.

로그인과 여러 기기

  • 오른쪽 위 버전 표시 → Google로 로그인. 휴대폰·PC 어디서든 같은 계정으로 로그인하면 같은 목록이에요.
  • 로그인 전에 쓰던 목록은 로그인하면 자동으로 계정으로 옮겨져요.
  • 로그인하면 위쪽에 내 사진과 이름(휴대폰은 "● 로그인됨" 줄)이 보여요. 누르면 내 계정과 로그아웃.
  • 두 기기에서 동시에 고쳐도 서로 덮어쓰지 않고 합쳐져요. 오른쪽 위가 동기화됨이면 저장 끝.

휴대폰 홈 화면에 설치

  • 안드로이드: 버전 표시 → 앱으로 설치 (또는 Chrome 메뉴 → 홈 화면에 추가).
  • 아이폰: Safari 아래 공유 버튼 → 홈 화면에 추가.
  • 설치하면 매장처럼 인터넷이 약해도 열리고, 아이콘에 오늘·지난 할일 개수가 떠요.

말로 추가하기 (안드로이드)

  • 버전 표시 → 내 계정 → 음성·단축어용 추가 주소를 복사해 MacroDroid에 넣어요. 자세한 설정은 저장소의 docs/voice-macrodroid.md에 있어요.
  • 말할 때도 적을 때와 같아요. 쉼표나 "그리고"로 여러 개: "우유, 계란 1판 그리고 대파"
  • 앱이 열려 있으면 20초 안에, 아니면 다음에 열 때 목록에 들어와요.

꿀팁

  • 장바구니 탭 입력칸 아래 + 우유 같은 최근 항목을 누르면 바로 다시 담겨요.
  • 장 보러 가기 전에 구입처 버튼으로 그 가게 것만 보면 빠뜨리지 않아요.
  • 매번 하는 일은 반복 할일로 한 번만 적어 두세요.
  • PC에서는 보드로 한 주를 정리하고, 휴대폰에서는 체크만 하면 편해요.

내 계정

Google로 로그인하면 목록이 내 계정 전용 공간에 저장돼요. 로그인한 본인만 읽고 쓸 수 있고, 휴대폰·PC 어디서든 로그인만 하면 같은 목록을 봐요.

Google로 로그인

음성·단축어용 추가 주소

MacroDroid·단축어에서 항목을 넣을 때 쓰는 주소예요. 이 주소로는 추가만 할 수 있고 목록을 볼 수는 없어요. 끝에 넣을 내용을 붙이세요.

다른 기기 연결

휴대폰과 PC에서 같은 목록을 보려면, 다른 기기에서 아래 연결 링크를 한 번 열어 주세요. 이 링크가 열쇠 역할을 하니 다른 사람에게는 보내지 마세요.

홈 화면에 설치

홈 화면에 앱으로 추가하면 주소창 없이 바로 열리고, 인터넷이 안 될 때도 열려요.

작동 원리

이 앱은 화면과 기능을 담은 앱 코드와, 내가 적은 목록을 담은 데이터(JSON)로 나뉘어 있어요. 앱을 업데이트하면 앱 코드만 바뀌고 데이터는 그대로 남아요.

  • 저장 위치: 이 기기의 브라우저 저장소
  • Google 로그인: 로그인하면 목록이 내 계정 전용 공간에 저장돼요. 서버가 매번 로그인을 확인해서 본인 목록만 열어 주고, 로그인 정보는 앱 코드도 읽을 수 없는 보안 쿠키에 보관해요.
  • 이 기기에도 한 벌: 같은 내용을 기기에도 저장해 둬서 인터넷이 잠깐 끊겨도 바로 열려요.
  • 저장 순서: 추가하거나 체크하면 화면과 기기에 바로 반영되고, 잠시 뒤 서버로 올라가요. 오른쪽 위 표시가 "동기화됨"이면 올라간 거예요.
  • 두 기기에서 동시에 고쳐도 안전: 항목마다 고친 시각을 기억해서, 휴대폰과 PC에서 거의 동시에 바꿔도 서로의 변경을 덮어쓰지 않고 합쳐요. 지운 항목도 다른 기기에서 다시 살아나지 않아요.
  • 인터넷이 끊겨도: 매장 안처럼 신호가 약해도 앱이 열리고, 적거나 체크한 건 기기에 저장됐다가 연결되면 바로 올라가요.
  • 업데이트해도 안전: 데이터에 저장 형식 번호가 붙어 있어서, 앱이 형식을 바꾸면 열 때 자동으로 변환해요. 모르는 항목은 지우지 않아요.
  • 구입처 인식: 맨 앞 단어가 아는 가게(다이소, 이마트, 쿠팡, 주유소, 철물점 등이나 한 번 쓴 가게)이거나 "동네마트", "행복약국", "SK주유소"처럼 가게 이름으로 끝날 때 구입처로 읽어요. 그 밖의 가게는 "@단골집 두부"처럼 적으면 기억해요.

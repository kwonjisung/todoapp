# 장바구니 · 할일 메모

살 것과 할 일을 적어 두고, 장 볼 때나 일을 끝낼 때 체크하는 모바일용 웹앱입니다.

- 탭: 전체 / 장바구니 / 할일
- 반복 할일: "매일 약 먹기", "매주 월 분리수거", "매월 15일 관리비" — 완료하면 다음 날짜로 새로 생김
- 끝낸 항목(장바구니 구매, 할일 완료)은 접힌 칸에 날짜와 함께, 7일 지나거나 "기록으로 보내기"를 누르면 "완료 기록" 팝업에만 남음 (데이터 삭제 없음)
- 할일은 "오늘 트럭 라이트", "11/17 차량 세차"처럼 앞에 날짜를 적으면 마감일로 인식 (없으면 마감없음)
- "다이소 우유 2개"처럼 적으면 구입처·항목·수량을 나눠 인식하고, 구입처별로 필터
- 오른쪽 위 버전 표시(v1.5)를 누르면 작동 원리와 버전 기록 팝업

## 구조

```
public/index.html            앱 전체 (HTML/CSS/JS 한 파일)
netlify/functions/list.mjs   데이터 저장 API (/api/list) → Netlify Blobs
netlify.toml                 배포 설정 (publish=public)
```

## 데이터 저장 (앱 코드와 분리)

목록은 앱 코드 안이 아니라 **Netlify Blobs** 저장소(`basket-lists`)에 JSON 문서로 저장됩니다.
Blobs의 사이트 전체 저장소는 배포와 따로 유지되므로, 앱을 다시 배포하거나 업데이트해도 목록은 그대로 남습니다.

- 각 사용자는 처음 열 때 무작위 열쇠를 받고, 데이터는 `lists/<열쇠>` 키에 저장됩니다.
- 다른 기기는 팝업의 "다른 기기 연결" 링크(`/#k=<열쇠>`)를 한 번 열면 같은 목록을 봅니다. 열쇠가 곧 접근 권한이니 링크를 공유하지 마세요.
- 기기에도 localStorage로 한 벌 저장해 두어 오프라인에서도 열립니다. 다른 기기의 변경은 화면을 다시 볼 때와 20초마다 받아옵니다.
- 같은 HTML을 claude.ai 아티팩트로 열면 계정 저장소에, 파일로 직접 열면 기기에만 저장합니다.

### 저장 형식

```json
{ "version": 4, "updatedAt": 0, "stores": ["다이소"],
  "lists": {
    "shopping": { "items": [{ "id": "", "store": "다이소", "text": "우유", "qty": "2개", "done": false, "createdAt": 0, "doneAt": 0 }], "recent": [] },
    "todo":     { "items": [{ "id": "", "text": "차량 세차", "due": "2026-11-17", "done": false }], "recent": [] } } }
```

형식을 바꿀 때는 `SCHEMA_VERSION`을 올리고 `MIGRATIONS`에 변환 함수를 추가합니다. 모르는 필드와 목록 유형은 지우지 않고 보존합니다.

## 앱을 열지 않고 추가 (`/api/add`)

음성 비서, 단축어, 자동화 앱에서 쓰는 주소입니다. `<열쇠>`는 팝업의 연결 링크 `#k=` 뒤 값입니다.

```
GET  /api/add?k=<열쇠>&text=다이소 우유 2개&list=shopping
POST /api/add?k=<열쇠>   {"text":"대파, 계란 1판", "list":"shopping"}   (list: shopping | todo)
```

안드로이드 음성 설정은 [docs/voice-macrodroid.md](docs/voice-macrodroid.md)를 보세요. 쉼표나 " 그리고 "로 여러 개를 한 번에 넣을 수 있습니다. 서버는 원문을 `inbox`에 넣기만 하고, 구입처·수량 해석은 앱이 다음에 열릴 때(또는 20초 안에) 앱 규칙으로 처리한 뒤 `inboxDone`으로 알려 줍니다.

## 버전 관리

앱 버전(`APP_VERSION`, 화면·기능)과 데이터 형식 버전(`SCHEMA_VERSION`)을 따로 관리합니다. 앱을 고칠 때마다 `APP_VERSION`을 올리고 `CHANGELOG` 맨 위에 추가하세요.

| 1.8.0 | 완료 칸 접기·완료 날짜, 7일 지나면 완료 기록으로, 완료 기록 팝업, 반복 할일(매일/매주 월/매월 15일), 데이터 형식 4번 |

## 배포

Netlify에서 이 저장소를 연결하면 `main`에 푸시할 때마다 자동 배포됩니다. 빌드 명령은 필요 없고, 함수 의존성(`@netlify/blobs`)은 Netlify가 설치합니다.

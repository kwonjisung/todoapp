# 장바구니 · 할일 메모

살 것과 할 일을 적어 두고, 장 볼 때나 일을 끝낼 때 체크하는 모바일용 웹앱입니다.

**처음이면 [사용법과 꿀팁](docs/how-to-use.md)부터 보세요.** 앱 오른쪽 위 "사용법" 버튼에도 같은 내용이 있어요.

- 탭: 전체 / 장바구니 / 할일
- 반복 할일: "매일 약 먹기", "매주 월 분리수거", "매월 15일 관리비" — 완료하면 다음 날짜로 새로 생김
- 끝낸 항목(장바구니 구매, 할일 완료)은 접힌 칸에 날짜와 함께, 7일 지나거나 "기록으로 보내기"를 누르면 "완료 기록" 팝업에만 남음 (데이터 삭제 없음)
- 완료 기록은 항목별 카드(목록·구입처·수량·반복·몇 번 했는지)로 보이고, "자주 한 것" 보기에서 반복되는 일을 묶어 보며 "+ 다시 추가"로 바로 목록에 다시 넣음. 앞의 네모로 여러 개 골라 한 번에 다시 넣을 수도 있고, 예전 기록은 지워지지 않음
- 할일은 "오늘 트럭 라이트", "11/17 차량 세차"처럼 앞에 날짜를 적으면 마감일로 인식 (없으면 마감없음)
- "다이소 우유 2개"처럼 적으면 구입처·항목·수량을 나눠 인식하고, 구입처별로 필터
- 큰 화면(900px 이상)에서는 오른쪽 위에서 보기 선택: 좁게(기존) / 나란히(남은 것·완료, 장바구니·할일을 옆으로) / 보드(구입처별·마감별 칸, 마우스로 끌어 다른 칸으로 옮기면 구입처·마감일이 바뀜. 전체 탭에서는 장바구니 ↔ 할일 사이로도 옮김)
- Google 로그인: 목록을 내 계정 전용 공간에 저장, 본인만 읽고 쓰기. 다른 기기도 로그인만 하면 같은 목록 ([설정 방법](docs/google-login-setup.md))
- 휴대폰·PC에서 동시에 고쳐도 항목 단위로 합쳐 저장 (덮어쓰기·지운 항목 부활 없음)
- 홈 화면에 앱으로 설치(PWA), 인터넷이 없어도 열리고 연결되면 자동으로 올림. 아이콘에 오늘·지난 할일 개수 배지
- 오른쪽 위 버전 표시(v1.5)를 누르면 작동 원리와 버전 기록 팝업

## 구조

```
public/index.html            앱 전체 (HTML/CSS/JS 한 파일)
public/sw.js                 서비스 워커: 앱 화면을 기기에 보관 (오프라인에서 열림, /api 는 보관 안 함)
public/manifest.webmanifest  홈 화면 설치 정보 + 아이콘(icon.svg, icon-*.png)
netlify/functions/list.mjs     데이터 저장 API (/api/list) → Netlify Blobs
netlify/functions/add.mjs      앱 밖에서 항목 추가 (/api/add)
netlify/functions/account.mjs  Google 로그인·세션·목록 옮기기·추가 전용 열쇠 (/api/me, /api/auth/*, /api/claim, /api/addkey)
netlify/lib/auth.mjs           로그인 확인·세션 쿠키
netlify/lib/store.mjs          저장소 공통(읽고 합쳐 쓰기, inbox 추가)
netlify/lib/merge.mjs          기기 간 합치기 규칙 (index.html 안에도 같은 코드)
test/*.test.mjs                합치기 규칙·로그인·계정 테스트 (npm test)
netlify.toml                 배포 설정 (publish=public)
```

## Google 로그인과 보안

Netlify 환경 변수 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`을 넣으면 켜집니다 ([설정 방법](docs/google-login-setup.md)). 없으면 예전처럼 열쇠 방식으로만 동작합니다.

- **로그인**: `/api/auth/login` → Google 로그인 → `/api/auth/callback`에서 서버가 Google과 직접 코드 교환(PKCE·state 확인) → id_token의 `aud`·`iss`·만료·이메일 인증 확인. 앱 화면에는 Google 스크립트가 들어가지 않습니다.
- **세션**: 무작위 값을 `__Host-sid` 쿠키(HttpOnly, Secure, SameSite=Lax, 180일)로 주고, 저장소에는 그 SHA-256만 `sessions/<해시>`로 저장. 로그아웃하면 지워지고, 기기의 목록 사본도 지웁니다.
- **계정별 목록**: `users/<Google id>`. `/api/list`는 세션이 있으면 그 사람 목록만 읽고 씁니다. 쓰기 요청은 `Sec-Fetch-Site`/`Origin`으로 다른 사이트에서 온 요청을 막습니다.
- **허용 계정**: Google 앱을 "테스트" 상태로 두면 테스트 사용자만 로그인됩니다. `ALLOWED_EMAILS`(쉼표 구분)를 넣으면 서버에서도 한 번 더 막습니다.
- **예전 목록 옮기기**: 로그인한 기기에 예전 열쇠가 있으면 앱이 `/api/claim`을 부릅니다. 서버는 원본을 `archive/<열쇠>`에 백업하고, 계정 목록에 항목 단위로 합친 뒤, `lists/<열쇠>`를 `{ moved: true }`로 바꿉니다. 이후 그 열쇠로 읽고 쓰면 410이 나오고 앱은 로그인을 안내합니다. 로그인 기능이 켜진 뒤에는 열쇠로 새 목록을 만들 수 없습니다.
- **추가 전용 열쇠**: `addkeys/<열쇠>` → 사용자. `/api/add`에만 쓰이고 목록을 읽을 수 없습니다. 옮긴 예전 열쇠도 추가 전용으로 남아 음성 설정이 끊기지 않습니다. 앱에서 새로 만들면 예전 열쇠는 지워집니다.

## 데이터 저장 (앱 코드와 분리)

목록은 앱 코드 안이 아니라 **Netlify Blobs** 저장소(`basket-lists`)에 JSON 문서로 저장됩니다.
Blobs의 사이트 전체 저장소는 배포와 따로 유지되므로, 앱을 다시 배포하거나 업데이트해도 목록은 그대로 남습니다.

- (로그인 기능이 꺼져 있을 때) 각 사용자는 처음 열 때 무작위 열쇠를 받고, 데이터는 `lists/<열쇠>` 키에 저장됩니다.
- 다른 기기는 팝업의 "다른 기기 연결" 링크(`/#k=<열쇠>`)를 한 번 열면 같은 목록을 봅니다. 열쇠가 곧 접근 권한이니 링크를 공유하지 마세요.
- 기기에도 localStorage로 한 벌 저장해 두어 오프라인에서도 열립니다. 다른 기기의 변경은 화면을 다시 볼 때와 20초마다 받아옵니다.
- **두 기기 동시 수정**: 항목마다 마지막으로 고친 시각(`mt`)을, 지운 항목은 `deleted`(`{id: 지운 시각}`, 90일 보관)에 남깁니다. 서버는 저장할 때 기존 데이터와 항목 단위로 합치고(`mergeState`), "읽은 그대로일 때만 쓰기"(`onlyIfMatch`)로 동시 저장이 겹치면 다시 합칩니다. 저장마다 `rev`를 1씩 올려 앱이 바뀐 걸 시계와 상관없이 알아챕니다. 형식 4번 이하로 보내는 예전 앱은 예전처럼 통째로 저장합니다.
- 합치기 코드는 `netlify/lib/merge.mjs`와 `public/index.html`의 `MERGE-START`~`MERGE-END` 사이에 똑같이 들어 있어야 하며, `npm test`가 확인합니다.
- 같은 HTML을 claude.ai 아티팩트로 열면 계정 저장소에, 파일로 직접 열면 기기에만 저장합니다.

### 저장 형식

```json
{ "version": 5, "updatedAt": 0, "rev": 12, "stores": ["다이소"], "deleted": { "<id>": 0 },
  "lists": {
    "shopping": { "items": [{ "id": "", "store": "다이소", "text": "우유", "qty": "2개", "done": false, "createdAt": 0, "doneAt": 0, "mt": 0 }], "recent": [] },
    "todo":     { "items": [{ "id": "", "text": "차량 세차", "due": "2026-11-17", "done": false }], "recent": [] } } }
```

형식을 바꿀 때는 `SCHEMA_VERSION`을 올리고 `MIGRATIONS`에 변환 함수를 추가합니다. 모르는 필드와 목록 유형은 지우지 않고 보존합니다.

## 앱을 열지 않고 추가 (`/api/add`)

음성 비서, 단축어, 자동화 앱에서 쓰는 주소입니다. `<열쇠>`는 로그인했으면 팝업 "내 계정"의 추가 전용 주소에 있는 값, 아니면 연결 링크 `#k=` 뒤 값입니다.

```
GET  /api/add?k=<열쇠>&text=다이소 우유 2개&list=shopping
POST /api/add?k=<열쇠>   {"text":"대파, 계란 1판", "list":"shopping"}   (list: shopping | todo)
```

안드로이드 음성 설정은 [docs/voice-macrodroid.md](docs/voice-macrodroid.md)를 보세요. 쉼표나 " 그리고 "로 여러 개를 한 번에 넣을 수 있습니다. 서버는 원문을 `inbox`에 넣기만 하고, 구입처·수량 해석은 앱이 다음에 열릴 때(또는 20초 안에) 앱 규칙으로 처리한 뒤 `inboxDone`으로 알려 줍니다.

## 배포

Netlify에서 이 저장소를 연결하면 `main`에 푸시할 때마다 자동 배포됩니다. 빌드 명령은 필요 없고, 함수 의존성(`@netlify/blobs`)은 Netlify가 설치합니다.

# 사용법과 꿀팁

앱 오른쪽 위 **사용법** 버튼을 누르면 같은 내용을 앱 안에서도 볼 수 있어요.

## 기본
- 위 칸에 적고 **Enter**(또는 추가).
- 왼쪽 동그라미 = 체크, 글자 누르기 = 고치기, 오른쪽 X = 지우기.
- 잘못 지우거나 체크했으면 아래에 뜨는 **되돌리기**.
- 탭: **전체**(둘 다 한눈에) / **장바구니** / **할일**. 전체 탭에서는 입력칸 왼쪽에서 넣을 목록을 골라요.

## 장바구니 적는 법
| 이렇게 적으면 | 이렇게 들어가요 |
|---|---|
| `다이소 우유 2개` | 구입처 다이소 · 우유 · 2개 |
| `대파` | 구입처 없음 · 대파 |
| `@동네마트 두부` 또는 `동네마트: 두부` | 처음 쓰는 가게. 다음부터는 `동네마트 두부`만 써도 돼요 |

- 앞 단어가 아는 가게(다이소, 이마트, 쿠팡, 편의점, 약국, 주유소, 철물점 등이나 한 번 쓴 가게)이거나 **동네마트**, **행복약국**, **SK주유소**처럼 가게 이름으로 끝나면 구입처로 읽어요.
- 구입처 버튼을 누르면 그 가게 것만 보여요. 그 상태로 적으면 그 가게 항목이 돼요.

## 할일 적는 법
| 이렇게 적으면 | 마감 |
|---|---|
| `오늘 세차`, `내일 병원`, `모레 택배` | 그날 |
| `11/17 관리비`, `11월 17일 회의` | 11월 17일 |
| `매일 약 먹기` | 매일 반복 |
| `매주 월 분리수거` | 매주 월요일 반복 |
| `매월 15일 관리비` | 매달 15일 반복 |

- 날짜가 없으면 마감없음. 마감이 가까운 순서로 정렬되고, 지난 할일은 빨갛게.
- 반복 할일은 완료하면 다음 날짜로 새로 생겨요.

## 끝낸 것과 완료 기록
- 체크하면 아래 접힌 칸(담은 것 · 완료)으로 내려가요. 다시 누르면 되돌아와요.
- 7일이 지나거나 **기록으로 보내기**를 누르면 목록에서 빠지고 오른쪽 위 **완료 기록**에 카드로 남아요. 지워지지 않아요.
- 완료 기록의 **자주 한 것**에서 몇 번 했는지 보고, 카드의 **다시 추가**로 바로 목록에 넣을 수 있어요.

## 나만의 색상
- 오른쪽 위 **색상**(팔레트 모양, 휴대폰은 그림만) 버튼 → 장바구니와 할일의 **색**(숲·바다·민트·남색·보라·벚꽃·딸기·귤·레몬·커피, 10가지)과 **바닥 무늬**(없음·점·사선·격자·타일)를 따로 골라요. 고르는 즉시 바뀌어요.
- 탭, 체크, 수량·마감 표시, 입력 버튼, 바닥이 그 목록 색으로 바뀌어요. 전체 탭에서는 목록 묶음마다 자기 색 바탕이에요.
- Google 로그인 중이면 내 계정에 저장돼 다른 기기에서도 같은 색, 아니면 이 기기에 저장. **기본 색으로**를 누르면 장바구니 초록 · 할일 파랑으로 돌아가요.

## PC · 태블릿 큰 화면 (900px 이상)
- 오른쪽 위에서 **좁게 / 나란히 / 보드** 선택.
- **보드**: 가게별 · 마감별(지남 · 오늘 · 이번 주 · 나중 · 마감없음) 칸. 항목을 마우스로 끌어 다른 칸에 놓으면 구입처나 마감일이 바뀌고, 완료 칸에 놓으면 체크돼요.
  - 오늘 칸 = 오늘, 이번 주 칸 = 내일, 나중 칸 = 7일 뒤, 마감없음 칸 = 마감 지움.
- **전체** 탭(보드 · 나란히)에서는 장바구니 ↔ 할일 사이로도 끌어 옮겨요. 옮긴 뒤 되돌리기도 돼요.

## 로그인과 여러 기기
- 오른쪽 위 버전 표시 → **Google로 로그인**. 어느 기기든 같은 계정으로 로그인하면 같은 목록.
- 로그인 전에 쓰던 목록은 로그인하면 자동으로 계정으로 옮겨져요.
- 로그인하면 위쪽에 내 사진과 이름(휴대폰은 "● 로그인됨" 줄)이 보여요. 누르면 내 계정과 로그아웃.
- 두 기기에서 동시에 고쳐도 합쳐져요. 오른쪽 위가 **동기화됨**이면 저장 끝.
- 로그아웃하면 그 기기에 남은 목록 사본도 지워져요.

## 휴대폰 홈 화면에 설치
- 안드로이드: 버전 표시 → **앱으로 설치** (또는 Chrome 메뉴 → 홈 화면에 추가).
- 아이폰: Safari 아래 공유 버튼 → **홈 화면에 추가**.
- 설치하면 인터넷이 약해도 열리고, 아이콘에 오늘 · 지난 할일 개수가 떠요.

## 말로 추가하기 (안드로이드 MacroDroid)
1. 앱에서 버전 표시 → 내 계정 → **음성·단축어용 추가 주소** 복사.
2. MacroDroid 매크로에 그 주소를 넣어요. 자세한 단계는 [voice-macrodroid.md](voice-macrodroid.md).
3. 말할 때도 적을 때와 같아요. 쉼표나 "그리고"로 여러 개: "우유, 계란 1판 그리고 대파".
4. 앱이 열려 있으면 20초 안에, 아니면 다음에 열 때 목록에 들어와요.

## 꿀팁
- 장바구니 탭 입력칸 아래 **+ 우유** 같은 최근 항목을 누르면 바로 다시 담겨요.
- 장 보러 가기 전에 구입처 버튼으로 그 가게 것만 보면 빠뜨리지 않아요.
- 매번 하는 일은 반복 할일로 한 번만 적어 두세요.
- PC에서는 보드로 한 주를 정리하고, 휴대폰에서는 체크만.
- 버전 표시를 누르면 작동 원리와 버전 기록도 볼 수 있어요.
